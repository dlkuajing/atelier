## 3. 纪律（每条都是真金白银换的，别省）

### 先用工具，别猜

- **推送前必跑 `scripts/impact_slice.py --base origin/main --pytest`**，按它给的清单跑测试。
  **别猜哪些测试相关**——猜错一次实测代价 **57min 失败 run + 57min 重跑 ≈ 114min**
- **施工走 loop-shovel 轻卡**：干净 `origin/main` 切 worktree → 原子提交 → 机器闸判绿 →
  `decisions.log` 一行

### CI 的真实成本

- `main` **没有分支保护**（私有仓非 Pro）——「CI 绿才合」是**约定不是闸**。
  合并前必须自己核 `gh run view <id> --json conclusion`；`gh pr merge` 没报错**不等于**过了
- **一个 PR 只推一次**。`concurrency: cancel-in-progress: true` 会 cancel 掉正在跑的那轮，
  每多推一次把 **57 分钟**清零。证据文档 / `decisions.log` / 交接单**攒成一次推送**
- ⚠️ **「纯文档 PR 跳过 CI」只对整个 diff 全是文档的 PR 成立**——
  `pull_request` 触发按**整个 PR 的 diff** 比 `paths-ignore`
- **CI 串行，别加 `-n`**（三次实测证伪；runner 实测 `nproc=2`）

### 测量陷阱（每条都中过招）

- **报比例前先确认分母的边界与成分**。这两轮栽了两次：先是**边界**（底库三个池），
  后是**成分**——24 条对照里 20 条的 spec 会被产品自己的参数闸拒收，
  而**赢的两条恰好全在域外**，8.3% 因此作废
- **比总数不能推重叠**，断言「不重叠」必须比**集合**
- **小样本的完美一致是假象（已中三次）**：8/8→92.9%、218/442→456/1055、n=9→n=53 方向翻转
- **退化值恰好等于理想读数（已中八次）**：新增任何指标先问「它失败时返回什么」。
  判据分**自证型**（正定量，单值可判）与**联合判据**（0.0 物理合法，须靠独立判别器）。
  **修一个假绿可能关掉另一个假绿的判别器**
- **第 8 例是精度不是哨兵**：CODE V `BUF EXP` 在 `1e-6~1e-4` 带按定点 6 位小数导出，
  高阶非球面系数最坏被削 **19%**，而值看上去就是个普通小数
- 读 ZMX **必须按 BOM 解码**；枚举用 `find data -iname "*.zmx"`（**必须 `-iname`**）

### 验证纪律

- **新测试必须先证明能失败**：拿到未修复代码上跑，失败才算有效捕获；
  旧码上也通过的，如实标注「契约钉」，不计入
- **自建探针先做阳性对照**，且用生产入口验证——更要问
  **「哪个生产入口才是本次改动的消费者」**。这一轮用 `run_codev_readout` 证了往返，
  但候选走的是 `codev_optimize` 的发射点，结果那次修复贡献实测为 **0**
- **两个发射点必须一致**：`codev_readout` 与 `codev_optimize._optimized_readout_block`
  写的是同一个解析器读的文件。已有通用守卫（surface key 集合必须相等），别绕过
- **`| tail -N` 会把输出全缓冲住**。长任务看似挂死先看进程 CPU
  （`Get-CimInstance Win32_Process`）。批量跑外部引擎**每项独立子进程 + 硬超时**
- **对抗审查当尽力而为，别排进关键路径**；没交付时走「自审 + PR 留证」，
  但**必须显式说明未交付**
- **本机测试**：`PYTHONUTF8=1`；新 worktree 无 `.venv`，用
  `PYTHONPATH=<worktree>` + `D:\atelier\.venv\Scripts\python.exe -m pytest`
