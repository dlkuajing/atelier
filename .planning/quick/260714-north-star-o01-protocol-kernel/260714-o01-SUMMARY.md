# Summary: O-01 strict preregistration and ITT protocol kernel

O-01 provides a small immutable interface with two operations: freeze exact preregistration content
and recompute ITT reports against a separately retained expected freeze-content hash. The module
hides strict input validation, closed-world ordering, parent reconciliation, domain-separated
hashing, eligibility execution, retry aggregation, exclusion default-deny, and evidence-availability
semantics behind those operations.

later backlog nodes and are not claimed here.
