# Summary: O-01 strict preregistration and ITT protocol kernel

O-01 provides a small immutable interface with two operations: freeze exact preregistration content
and recompute ITT reports against a separately retained expected freeze-content hash. The module
hides strict input validation, closed-world ordering, parent reconciliation, domain-separated
hashing, eligibility execution, retry aggregation, exclusion default-deny, and evidence-availability
semantics behind those operations.

The first `0ae75a9/5937ae7`, second `66331983/f3ab3aaf`, third `2d467ae6/344074d6`,
fourth `cc409880/f5cd22c9`, fifth `536e26f/23ad364f`, and sixth `17a2eaa/87c50bf` fixed trees
are rejected and forbidden to publish. Their review findings drove a strict annotation-directed model
graph, exact built-in model storage with exact physical string keys, required exact-None Pydantic
hidden slots, identity-only rejection paths, one-pass cycle-rejecting exact built-in raw
snapshots, an exact frozen root, before/after runtime
type comparison, complete freeze-content binding (including eligibility time and the returned report),
and an explicit split between the zero-valued non-diagnostic pipeline metric and caller-reported
terminal diagnostics. Rejected exclusions remain in the denominator and force their scope not-passed.
Candidate reported delivery follows a frozen aggregation rule; its conditional selection ledger
retains ordered members and every influencing rejected run/candidate exclusion hash.

The implementation remains deliberately non-authoritative. It accepts neither submitted eligibility
decisions nor expert pass booleans, recognizes no O-01 exclusion as valid, and marks verified machine
terminal evidence, expert evidence, duplicate-cluster evidence, and confidence intervals unavailable.
Duplicate caps, formal exclusion verification, real machine receipts, and expert labels belong to
later backlog nodes and are not claimed here.

The sixth-review fix-forward fixed-tree candidate passed 91 targeted tests, Ruff, mypy, and the full
offline regression suite (`2267 passed, 1 skipped, 545 deselected`). A seventh-iteration adversarial
review (39 agents) then confirmed 11 findings against it: 2 BLOCKER resolved via the backlog's
recorded execution split plus schema-hash binding, 1 MAJOR bug fixed, MAJOR claim/coverage gaps
closed, and 5 MINOR fixed.

## Seventh iteration: O-01a scope and fixes

Per the recorded execution split in `.planning/north-star/backlog.md` (2026-07-16, no clause
deleted or reworded), this slice is **O-01a**: the preregistration/ITT kernel with its owned
vectors. The two BLOCKERs were resolved by that split plus a new binding obligation:
`canonical_schema_template_hash` is now a required, strictly format-validated
`PreregistrationSpec` field that flows into the freeze-content hash preimage, is exposed on
`FrozenPreregistration`, and must equal a separately retained
`expected_canonical_schema_template_hash` on every `recompute_itt` call. This is a BINDING check
only: recomputation from exact final schema bytes under the out-of-band bootstrap suite and
cross-manifest equality land with X-00A/O-01c per the split. An internally self-consistent foreign
frozen object with an attacker-recomputed coherent expected freeze-content hash still rejects on
the retained schema-template hash (splice vector).

The MAJOR reproduced bug: `freeze_preregistration` built mapping/eligibility content outside
exception translation, so any empty ordered member array leaked a raw pydantic `ValidationError`
(PositiveInt count fields) instead of `ProtocolViolation`. Fixed with an explicit nonempty
pre-check on all four ordered member arrays before any content-model construction, plus
defense-in-depth `ValidationError`→`ProtocolViolation` translation around all derived content
construction (shared with `_as_model`). The previously unreachable
`all mapping member sets must be nonempty` guard was removed: declared counts are PositiveInt and
the declared==actual check precedes it, so no dead code path remains.

Coverage gaps closed with named tests: non-string raw mapping keys and BaseModel instances
embedded in raw dict/list payloads. The 5 MINOR fixes: reachable types exported from the package
root; module docstrings on `protocol.py`/`itt.py`/`_canonical.py`; all five hash-domain constants
pinned as independent test literals; the run/candidate population test made asymmetric (8 planned
runs vs 4 candidate slots) so a population swap is detectable; and an INELIGIBLE-decision vector
proving eligibility decisions never shrink ITT denominators.

The seventh fixed tree passes 105 targeted tests, Ruff, and mypy. The full offline regression
suite, three fresh independent read-only reviews, and the PR/CI/merge/main-CI release chain remain
pending for this tree. **O-01 parent closes only when O-01b–O-01e also close; this slice claims
O-01a only.** A-F and `valid_external_human_go` remain false; `[EXPERT]`, manufacturing yield,
and human GO remain unavailable.
