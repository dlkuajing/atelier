# Quick 260716: vd=0 不得由 Optiland 伪成 50（unknown dispersion fail-closed）

## Problem

`app/core/zmx_materials.py::resolve_material` branch 2: an unknown glass name with a
usable placeholder index (`fallback_nd > 1.4`) but unusable dispersion (`fallback_vd`
0/None) silently built `AbbeMaterial(fallback_nd, 50.0)` — a fabricated Abbe number
reported as if measured, with no provenance marker and no warning. This contradicts the
module's own "no values are fabricated" contract and the codebase's honest convention
(`engines/codev_readout.py` maps vd 0/None -> vd=None + vd_source=None; `engines/zmx_writer.py`
writes unknown vd as Zemax's explicit "unspecified" 0.0).

## Fix

Fail closed: branch 2 now requires a real, finite `fallback_vd > 0`; a usable placeholder
index with unknown dispersion raises a clear ValueError naming the material and the remedy
(supply real nd/vd or add it to MATERIAL_ND_VD). The index-only alternative (Optiland
`IdealMaterial`) was rejected because it claims zero dispersion — a different fabrication.
Call-site analysis supports raising: `resolve_material` has no production callers (grep:
only tests/test_zmx_ingest.py); production ZMX ingest resolves glass via
`optiland_patches._patched_read_glass` -> `lookup_nd_vd`, which returns None for unknowns.
Branch 3 (unusable nd -> warned conservative 1.54/56 default) is pre-existing documented
behavior and is left unchanged (out of scope).
