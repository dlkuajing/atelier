## Directory Purposes

**`app/`:**
- Purpose: Python FastAPI application (source code)
- Contains: API routes, business logic, data models, configuration
- Key files: `main.py` (entry), `api/` (routes), `core/` (logic), `data/` (assets)

**`app/api/`:**
- Purpose: HTTP route handlers
- Contains: Request/response schemas, endpoint implementations
- Key files: `optical.py` (raytrace/MTF/SVG), `wizard.py` (LLM intake), `rag.py` (search)

**`app/core/`:**
- Purpose: Reusable business logic (not HTTP-specific)
- Contains: Optical computation, Pydantic models, database/external integrations
- Key files: `optical_engine.py` (Optiland), `case_library.py` (matching), `parameter_guards.py` (validation)

**`app/core/rag/`:**
- Purpose: Pluggable search backend (abstract + implementations)
- Contains: Abstract interface (`LensPatentStore`), mock keyword store, pgvector stub
- Key files: `store.py` (interface + mock)

**`app/data/optical_cases/`:**
- Purpose: Real 39-case library (JSON, cached at runtime)
- Contains: One .json file per design (paraxial, surfaces, trace, MTF, metadata)
- Key files: `index.json` (manifest), `3P_F2.5_*.json`, etc. (case data)
- Generated: By `scripts/generate_cases.py` (not committed; regenerated on-demand)

**`data/zmx/`:**
- Purpose: Zemax source files (original prescriptions)
- Contains: 39 .zmx files (binary or text, Zemax format)
- Generated: Manually curated, stored as-is

**`scripts/`:**
- Purpose: One-off utilities, CLI tools, intake/validation pipelines
- Contains: Patent crawler, case generation, acceptance testing, bounds derivation
- Key files: `patent_crawler.py` (USPTO/Espacenet), `generate_cases.py` (ingest), `evaluate_design_agent.py` (testing)
- Executed: Manually or by CI/CD

**`tests/`:**
- Purpose: Pytest test suite (unit + integration)
- Contains: 20+ test modules, ~131 tests total
- Key files: `test_health.py` (smoke), `test_optical_engine.py` (raytrace), `test_case_library.py` (matching)
- Run: `uv run pytest` (local), CI on Ubuntu

- `.env.example` — Template for OPENAI_BASE_URL, OPENAI_API_KEY, EPO_OPS_KEY, etc.

**Core Logic:**

**API Routes:**

**Data Assets:**

**Testing:**

## Naming Conventions

**Files:**
- `*_engine.py` — Orchestration layer (e.g., optical_engine.py, llm_relay.py)
- `*_calc.py` — Pure computation (e.g., optical_calc.py)
- `*_ingest.py` — Data loading/parsing (e.g., zmx_ingest.py)
- `*_guards.py` — Validation (e.g., parameter_guards.py)
- `test_*.py` — Pytest test modules

**Directories:**
- `app/api/` — FastAPI routers (HTTP)
- `app/core/` — Business logic (reusable, non-HTTP)
- `app/data/` — Static assets (optical cases, etc.)
- `data/` — External data (ZMX files, etc.)
- `scripts/` — CLI utilities, one-off tools
- `tests/` — Test suite
- `.planning/` — GSD phase tracking (not part of app)

**Functions & Classes:**
- `Scenario` (StrEnum) — First-class use-case enum
- `OpticalSpecRequest` (BaseModel) — HTTP request schema
- `OpticalSampleData` (BaseModel) — Full case payload (composite)
- `RayTraceResult` (BaseModel) — Paraxial + surfaces + rays
- `LensAssembly` (BaseModel) — Full optical prescription
- `build_optic_for_scenario()` — Factory for Optiland optics
- `raytrace_from_spec()` — High-level ray trace endpoint
- `match_case()` — Seed selection + scoring
- `validate_scenario_params()` — Parameter guard gate

## Where to Add New Code

**New Optical Calculation (ground-truth formula):**
- Primary code: `app/core/optical_calc.py`
- Tests: `tests/test_optical_calc_extensions.py`
- Pattern: Add static method + docstring + unit test

**New API Endpoint:**
- Primary code: `app/api/optical.py` or `app/api/wizard.py` (depending on domain)
- Request/response schemas: Same file (BaseModel classes)
- Tests: `tests/test_api_optical.py` or equivalent
- Pattern: Add `@router.post()` handler, validate with `_validate_or_400()` or equivalent, call core logic

**New Scenario:**
- Scenario enum: `app/core/lens_system.py::Scenario` (add StrEnum member)
- Bounds: `app/core/parameter_guards.py::SCENARIO_BOUNDS` (add ScenarioBounds entry)
- Reference design: `app/core/optical_engine.py::_SCENARIO_REFERENCE` (add scenario → Optiland class mapping)
- Wizard system prompt: `app/api/wizard.py::SYSTEM_PROMPT` (document bounds, update LLM)
- Tests: `tests/test_parameter_guards.py` (add bounds validation), `tests/test_optical_engine.py` (test reference design)

**New Real Design (39 → 40+):**
- Source file: `data/zmx/NEW_DESIGN.zmx` (manually add)
- Case generation: Run `scripts/generate_cases.py` (regenerates `app/data/optical_cases/index.json` + .json files)
- Validation: Run `scripts/audit_seed_intake.py` (ensures design meets intake criteria)
- Tests: `tests/test_case_library.py` will auto-discover via index.json

**New Utility/Helper:**
- If shared across multiple modules: `app/core/` (create new file or add to existing)
- If private to one route: Keep in `app/api/` file where used
- Pattern: Pure functions, no side effects, unit-tested

**Optiland Bug Fix:**
- Primary code: `app/core/optiland_patches.py`
- Pattern: Add `def _patch_*()`, register in `apply_all()`
- Ensure: Import and call `apply_all()` in `app/main.py` (already done)

**RAG Store Upgrade (mock → pgvector):**
- Primary code: `app/core/rag/store.py`
- Pattern: Add `class PgVectorLensPatentStore(LensPatentStore)`, implement `search()`
- Config: Add env var (e.g., `pgvector_host`, `bge_api_key`) to `app/core/config.py`
- Update: `app/core/rag/__init__.py::get_default_store()` to check config and return correct store
- Tests: `tests/test_rag.py` (add PgVector test fixture)

## Special Directories

**`.planning/`:**
- Purpose: GSD phase tracking + generated codebase maps
- Generated: By `/gsd:*` commands (do not edit by hand)
- Committed: Yes (documents are tracked)

**`.github/workflows/`:**
- Purpose: CI/CD (GitHub Actions)
- Files: `pytest.yml` (tests on Ubuntu), `deploy.yml` (Docker push to fly.io)
- Committed: Yes

**`.env` file:**
- Purpose: Local development (never committed)
- Location: Project root
- Template: `.env.example`
- Contains: OPENAI_BASE_URL, OPENAI_API_KEY, EPO_OPS_KEY, EPO_OPS_SECRET, DATABASE_URL, etc.
- Gitignored: Yes

**`venv` / `.venv/`:**
- Purpose: Python virtual environment (uv manages)
- Committed: No (gitignored)

**`.pytest_cache/` / `__pycache__/`:**
- Purpose: Test runner cache, Python bytecode
- Committed: No (gitignored)
