## 1. PER 概率位列语义（钉死）

- 四概率位 50.0/84.1/97.7/99.9 PCT = **累积概率位**（正态 0σ/1σ/2σ/3σ 对应位；手册 p.125-126,
  128：97.7% 位标注 "Probable change"，含义 =「97.7% 的量产系统性能损失不超过该值」）。
- `Design + tolerances` 四列 = Design + 该概率位的 probable change；`Changes` 四列 = probable
  change 本身（**带符号、单位=criterion 本身单位**，MTF 即 MTF 差值）。
- **真机样本逐行验证加法恒等式**：0.0699+5.014=5.084 ✓；0.4505+(-31.617)=-31.166 ✓；
  0.0257+100.901=100.927 ✓（三场全对）。
- **列值不是概率、不是百分比、不是 [0,1] 有界量**——超界值（±5~±200）来自 TOR 的
  **多维二次（wavefront differential）模型外推**：手册 p.151 明言二次近似仅对参数小变化有效；
  本样本 baseline 在 100 lp/mm 离轴 MTF 本就崩（0.026-0.45），默认公差相对灵敏度巨大 →
  模型跑出信任域。**这是信号不是错误：必须上报，禁止静默采用。**
- 结论：**PER 概率位列不可直接当良率**；它是模型位分位数，可用于"设计+公差后性能"叙述，
  但在超界/外推场景不可信。

## 2. MC Value 语义（钉死）

- 手册 p.125-126：TOR 的 Monte Carlo 是对**二次模型系数**的模拟（非逐样本真光线追迹）。
- 0/1 饱和根因：模型外推幅度 ±5~±200 ≫ MTF 物理域 [0,1]，输出被裁剪到物理界——
  真机 20 样本×3 场全部 ∈ {0,1} 与 PER 超界幅度自洽。**裁剪行为为经验实证，手册未见
  显式声明**（诚实标注：empirical, not manual-documented）。
- 高饱和占比 = 模型出信任域的哨兵。此时按阈值数样本算出的"良率"反映的是模型外推
  + 裁剪，**不是镜头**——必须 fail-closed。

## 3. 对 tor_yield 策略的落地含义

1. 语义门（本文档）：已钉死 → 代码可引用本文件为 `semantics_evidence`。
2. 良率算法：MC 裸样本按阈值逐样本逐场判定 → 比例。阈值本身=资深 ratify 项，代码不得默认。
3. **饱和守卫**：`saturation_fraction`（值恰为 0 或 1 的样本占比）超门限 → yield 一律
   unavailable（门限=资深 ratify 项；未 ratify 前任何饱和>0 应如实上报并保持 unavailable）。
4. 阳性对照（真机矩阵必做）：优化后候选 + 信任域内频率（如 MTF 设计值 0.3-0.7 的频点）
   预期 PER 列落在合理 MTF 差值域、MC 值散布于 (0,1) 内部——用于交叉验证本口径。
   若阳性对照不符合预期，本文档口径作废重查（可证伪性）。

## 4. 遗留资深 ratify 项（诚实边界，不代填）

- 良率阈值（criterion+频点+方向）。
- 饱和门限。
- 公差表本身（当前 DEF TOL 默认表=供应商 capability 未注入，见 PR#64 设计）。

## 5. 阳性对照实测结果（2026-07-11 10:5x 真机窗，§3.4 可证伪性检验回填）

- 对照design：真实设计 5P_F1.9_FOV77.0_EFL3.6（库内量产级 seed，非候选）；CMP DLZ SI；NTR 100。
- **机制面全部验证通过**：导入/TOR/双导出/解析（含补偿器列）端到端 ok；FRE 50 处 Design MTF
  0.32-0.42（信任域中段）；补偿器列（DLZ S16）解析正确。
- **★关键实测：即便良设计+信任域频点，MC 饱和仍 91.6%（FRE 50）/ 85.8%（FRE 100）★**——
  CODE V `DEF TOL` 默认公差表对手机镜头量级过粗（默认公差在 ~4mm EFL 塑料镜片上物理性
  摧毁 MTF，模型预测的性能散布远超 [0,1] 物理域）。PER 概率位列在 1σ 外即出物理域
  （良设计 FRE50 的 3σ change ≈ -2.3 ~ -7.9）。
- **口径修正（对 §2 的精化，非推翻）**：高饱和不必然意味着"模型出信任域"——也可能是
  "默认公差真实地摧毁该镜头"。两种情形下按阈值数饱和样本得到的"良率"都不反映可制造性
  决策需要的信息 → **饱和守卫结论不变**（高饱和⇒yield unavailable）。
- **升级结论：公差表=第一位的资深 ratify 项**——"供应商 capability 注入"从设计声明升级为
  真机实证必需（默认表在两族 baseline 上饱和 0.82-0.997，在良设计上 0.86-0.92，全部无法
  用于良率判定）。
- **Mode3 候选缺口（另案）**：四颗优化候选在 TOR clear-aperture trace 全部 abort（渐晕裁剪
  未持久化进 ZMX，全口径追迹 TIR）→ TOR-on-候选需渐晕重施工程，与 Phase 15 Stage B
  光线可追迹主题同根（见 p15-stageb-evidence）。新鲜性契约正确 fail-loud，零假数据。
