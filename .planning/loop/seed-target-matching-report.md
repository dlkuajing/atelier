- 机制上合理但仅为待验假说：EFL 上拉在冻结 TTL/口径格局下更容易把边缘光线推向 TIR；缩焦则是"往里收"。

## 6. 打分 heuristic 草案（喂路由；lower = 更近的"良配"，非合格判定）

**score = |ΔEFL%| + 1.0 × max(0, ΔEFL% − 20)**

- 第 1 项：|ΔEFL|% —— 收敛内质量最强预测子（rho=+0.744）兼收敛主因子（rho=-0.645）。
- 第 2 项：拉焦超 +20% 的线性惩罚 —— 编码方向不对称（正向 +25.1% 起见失败，负向 -35.6% 仍全收敛）。惩罚起点 20% 取整于失败下界 25.1% 之下留 margin；斜率 1.0 是最保守的 1 档（等权重复计超出部分），**不是拟合值**。
- 刻意不加第 3 项：baseline RMS 在收敛组合内无信号（p=0.63）；面数信号弱（p=0.04 仅一侧且 N=19）；F# 不显著（p=0.15）。宁缺毋滥。

参考带（分桶经验对应，供路由排序/预警，**不是良品线**）：

| score | 经验对应 |
|---|---|
| < 5 | conv 100%，RMS 中位 ~6µm |
| 5–15 | conv 100%，RMS 中位 ~35µm |
| 15–30 | conv ~86%，RMS 中位 ~46µm |
| > 30 | conv ≤43%，RMS 中位 ~274µm |

**诚实标注**：N=24（收敛内 N=19），单一 heuristic 由同一数据集读出又在其上"验证"，属描述性拟合而非外推证明；系数与阈值精度不超过 ±1 档桶宽。

## 7. 限制与异常事实

**限制**：
1. **N 小**：8 seed × 3 target = 24；每桶 3–7 个点。相关系数 ±0.2 内的差异无意义。
2. **RMS 在裁瞳光栅上测**：渐晕越大（0.3/0.5/0.7），RMS 数字越"取巧"（边缘光被弃后测的），跨渐晕档的 RMS 不严格可比——所有结论须连同渐晕列读。
3. **单 target 维**：只扫了 EFL；F#/IMH/TTL 距离维未进本矩阵（stage A only）。
4. **Stage A + asphere 固定配置**：换 stage/DOF/ladder 结论可能移动；与前次 autovig 报告数字不可横比（配置不同）。
5. **共线陷阱**：target 取自池分布的绝对值 ⇒ 原生 EFL 与带符号偏移强相关，"原生 EFL / baseline RMS 预测收敛"是伪信号，heuristic 刻意未采用。
6. **池偏差**：8 颗全为可追迹幸存者（3 场居多、EFL 2.4–5.0），对不可追迹/极端规格 seed 无外推力。

**异常事实**：
1. **US20180143405A1 三度证实不可用**：一阶读数即 60s 超时（本轮 62.4s），与前两份报告一致；任务简报"已知可追迹 5 颗"应更正为 4 颗。
2. **首次筛选进程静默死亡**：第一次以后台方式启动筛选，进程在 5 个决策后无声消失（stdout 全缓冲未落盘，无 python/codev 残留进程）；疑与后台 harness 派生进程回收有关（此前已知孤儿进程风险）。改为断点续跑设计 + 前台分片轮询后全程无再发。CODE V 侧无串扰观察（严格串行）。
3. **US20140111876A1 的 baseline RMS=111µm、WFE=0.000**：baseline 读数疑受该 seed 导入态影响（WFE=0 非物理），其 rms_ratio<1 的三行（优化后反而变好）应按 post 绝对值读，不按倍数读；WFE 倍数为 nan 的行同理（US9810880B2 baseline WFE=0）。
4. **US9810880B2（5 场，唯一）单组合耗时 141–175s**：5 场光栅 + 多级渐晕爬梯所致，非卡死。
5. US20210165194A1 T3 行 post WFE=0.000（非物理读数），该行 WFE 不可信；RMS/畸变列不受影响。
