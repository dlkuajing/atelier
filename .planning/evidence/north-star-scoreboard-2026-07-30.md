## P2 · 异源打平率（主指标）

| | |
|---|---|
| 当前批跑（旧 seed 池，基线） | 40 条已判，**judged 28 / par 0** |
| 候选落败幅度 RMS（候选/对照） | 中位 **16.7×**，区间 6.9–54× |
| 候选落败幅度 MTF | 中位 **0.022×**（对照 0.56–0.71 vs 候选 0.001–0.104） |
| 打平率门槛 | **按北极星规定留空，待实测** |

**根因已定位**：路由质量闸 `_SEED_ROUTING_MAX_RMS_UM = 100.0` 比要打平的对照
（2.3–11.2 µm）**松 10–45 倍**，且它读 Optiland **半径 / 半场**而判决读 CODE V **全场直径**。
承担 41/49 的那颗 seed 原生就是 **101.27 µm**。

**⚠️ 本节原写「按语料中位数设闸、零 trial 代价」—— 已被同日真机推翻，更正如下。**

那个「零代价」测的是**规划出的 trial 数**，而消费者要的是**能收敛的 trial 数**。
只按质量设闸会把 **53/59** 条推过实测的 **+25% 拉焦上限**，真机 4 条即
`aut_not_converged`（EFL 偏差 13.97% / 17.02% / 22.64%）。

**正解是联合闸：可达优先、质量其次、都无则回退并留痕。**

| | 需要 >+25% 拉焦 | seed RMS 中位 | `seed_pool_basis` |
|---|---|---|---|
| 无闸（原始） | 3/59 | 101.27 | — |
| 只按质量 | **53/59** | 8.75 | — |
| **联合** | **0/59** | 101.27 | **`reachable_only` 53 / `both` 6** |

⇒ **由此暴露的才是真发现：59 个对照里只有 6 个**存在「既在 +25% 拉焦内、
又达语料中位像质」的异源 seed。**par=0 的更深层原因是底库供不出这样的 seed**，
对 53/59 必须在「能收敛」与「够好」之间二选一 —— **不能兼得**。
这不是代码缺陷而是底库覆盖的事实，并指出两条路径：**扩底库让交集变大**（资产），
或**把 +25% 这个能力上限往外推**（能力）。

详见 `.planning/evidence/reachability-quality-conflict-2026-07-30.md`。

## 今晚定位的可信度级缺陷（全部实测，均已修或已记账）

1. **裁瞳映射对调** ⇒ 对称裁瞳变成「满宽瞳孔偏心 + 上缘越界」，13 条裁瞳 trial 里 12 条同签名丢场。已修（#146 在 main）。
2. **路由质量闸口径三重错配**（单位 / 视场集 / 引擎）⇒ 一颗 CODE V 认定 **447.60 µm** 的镜头在存量里长成 **2.38 µm**（**188×**），钻过 100 µm 闸。P2 侧已修，产品侧已记账。
3. **存量像质 94.3% 只测到部分视场** ⇒ 系统性低估，且**越坏的镜头被低估越多**。
4. **诊断探针无时间上限** ⇒ 一次挂死就是一次无限期 HTTP 请求。已按各自实测 10× 加界。
5. **度量宏对追迹失败的视场静默跳过** ⇒ 丢场读作「更好」。已补见证量。
6. **`rank_seeds` 权重是在混单位池上调出来的** ⇒ fov 项现在压倒 EFL，长焦选出 54% 焦距失配的 seed。已 `xfail(strict)` 记账。
