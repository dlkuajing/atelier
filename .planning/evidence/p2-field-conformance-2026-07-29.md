# P2 主指标此前判的不是同一件事：候选的视场从来不是 spec 的视场（2026-07-29）

**一句话**：优化链路**根本不设置像高/视场**，候选原样继承 seed 的视场定义；
把新的同场判据回灌到 2026-07-29 那 6 条 trial，**judged 从 2 掉到 0**——
异源打平率至今**没有一个有效读数**，之前的 `0/2` 是拿两条跨视场的比较凑出来的。

## 根因（源码自述，非推断）

`app/core/engines/codev_optimize.py`（`build_target_standard` 文档串）：

> 未落地：IMH/FOV（Stage C 场重建；`target_imh_mm` 目前仅透传进三快照读数，
> AUT merit 未加 IMH/FOV 操作数）。

`scripts/p2_crosssource_trial.py` 每条 trial 都传 `target_imh_mm=plan.spec_imh_mm`，
**看起来**像高被瞄准了；实际它只落进读数快照，不进 merit、不改视场。
NORTH-STAR §1.1 的输入 spec 明列「像高」与「FOV」，这两项从未被执行。

## 实测：候选的视场来自 seed，不来自 spec

同一颗 seed（`US-12044826-B2-e4`）在两条 EFL 不同的 trial 上，
候选的 `imh/efl` **都等于 0.3317**（= tan 18.35°）：

| control | spec EFL | 候选 EFL | 候选 `imh/efl` | 对照 `imh/efl` | 覆盖比 |
|---|---|---|---|---|---|
| `US-12210142-B2-e1` | 5.312 | 5.312 | 0.3317 | 0.7674 | **0.432** |
| `US-20250370227-A1-e12` | 8.574 | 8.574 | 0.3317 | 0.6521 | **0.509** |

EFL 被精确打中（偏差 2e-11 / 4e-11 %），视场角**纹丝不动**。
这正是「改了输入≠变量真的变了」——两条 trial 的 EFL 证明输入生效了，
而视场证明另一半输入从头到尾是装饰。

## 这会把主指标推向好看的方向

`US-20230288669-A1-e2` 那条：对照畸变 **86.97%**，候选 2.38%，
比值 0.027 → 该条 metric 判 **par**。只有 `aut_converged=0` 顺手挡住了它。

**对照的 86.97% 是对的，不是坏数**——先前把它记作「不可能值却过了三把尺子」是我判错了：

- 该颗声明像高 3.579 mm、EFL 2.354 mm，`^maximh`（CODE V 由近轴数据填，
  即 `EFL·tan θ`）读出 **27.470 mm**；
- `27.470 / 2.35504 = 11.6645 = tan(85.1°)`，与 index 里的视场值**逐位吻合**；
- 等距投影 `f·θ = 2.3543 × 1.48528 rad = 3.497 mm`，与声明像高 3.579 差 2.3%。

也就是说它是一颗**真的超广角**（半视场 85.1°），真实像高远低于直线投影参考，
而畸变的定义就是相对 `EFL·tanθ` 量的：`(3.58−27.47)/27.47 = −87.0%`，
与读数 86.97% 吻合。**尺子没漏，是两颗镜头根本不在同一个视场上。**
（这与 `hfov-label-audit-2026-07-28.md` 已记的「81° 半角是真超广角、
`sanity_image_height_mm` 的直线投影假设对这类镜头偏 3.5–4×」是同一现象。）

## 判据（无可调门槛）

一条 trial 只有在候选**不曾被派更轻的活**时才进 judged：

1. **同场**：候选 `tan θ` ≥ 对照 `tan θ`，其中 `tan θ = image_height_mm / efl_y_mm`，
   两侧同一探针、同一推导。超额覆盖照判——那只会让候选自己更难赢。
2. **同口径**：候选 F/# ≤ 对照 F/#。更慢的镜头白拿更小的像差。

两条都不是"调到多少算过"的阈值，都是"不许比对照容易"。
`CONFORMANCE_RELATIVE_SLACK = 1e-3` 是读数取整余量（探针 6 位有效数字、
自身相对误差约 1e-6），不是质量门槛，红线③不适用。
任一侧读不出 → **fail-closed** 判 `field_not_comparable` / `f_number_not_comparable`，
不静默比较。

## 对北极星的定位

卡点确认在 **P1 产出能力**，且比先前记的更靠前一层：不是"候选质量差"，
是**候选压根不是该 spec 的设计**。候选在更小的视场上被评价——那是**偏袒**候选的方向——
仍然差对照 30–65×。所以先前那句"候选是坏镜头"不但成立，还是被高估过的。

**下一铲**：优化前把 seed 视场重建到 spec 视场（`codev_optimize` 自述的
"Stage C 场重建"）。在它落地前，P2 跑全量拿不到有效样本——同场筛会把它们全部拦下。
