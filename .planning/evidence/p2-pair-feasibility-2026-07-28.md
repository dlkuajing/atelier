# P2 异源 trial 可行样本量普查 · 2026-07-28

**一句话**：北极星主指标（异源打平率）目前零数据。测打平率之前先要回答一个前置问题——
**底库到底撑得起多少个异源 trial**。答案是 **167**（`data/zmx` 池）。

**但 167 不是有效样本量**：这 167 个 trial 只用到 **31 颗不同的 seed**，
其中 **99 个（59.3%）由 5 颗 seed 承担**。**报 P2 时把 167 当独立样本量会严重高估置信度。**

本文只数 trial，**不产出任何打平率或质量数字**。

## 为什么先问这个

`.planning/NORTH-STAR.md` §3 把异源打平率列为 P2 主指标，门槛「待实测、禁止先验拍板」。
但门槛能不能测出来，先取决于样本量。一个 trial 需要：

- 一颗**对照专利原设计** C（必须可用：严格可追迹 ∧ 保真度干净）
- 一颗 spec 相近的 **seed** S，且 **S 与 C 不同专利家族**

## 异源判定：刻意过宽，只许错向同源

**危险方向只有一个**：把同源对判成异源。流程是
`spec → 最近 seed → 优化 → 候选`，若 seed 就是对照专利的亲戚，
「不劣于它」是循环论证，主指标白涨。反过来，把异源对误排除只损失样本量。
所以**一切歧义一律判同源，provenance 无法确立的 case 直接剔除**。

**仓库没有权威家族数据**：没有 INPADOC/DOCDB family id；`data/patents/*.jsonl` 里的
`family_hint` 是 assignee+title 近重复启发式，只覆盖 360/714 条发现记录。
因此规则退到 **assignee 品牌**桶——对本语料而言它是家族关系的**保守超集**
（家族成员共享 assignee，故同品牌必然「同家族或未知」）。代价真实，见下。

### 归一化是必须的（第一版有 fail-open 漏洞）

原始 assignee 字符串把同一家公司拆成多个桶：

| 公司 | 语料中的拼写数 |
|---|---|
| Sunny | 3（`ZHEJIANG SUNNY OPTICS CO., LTD.` / 无句点 / `Optical`） |
| AAC | 4 |
| Ability | 2（其中一个用的是 **em-dash** `OPTO—ELECTRONICS`） |
| Samsung | 2 |

**未归一时，同公司的两颗专利会被判成异源。** 归一后 15 个原始字符串塌成 **6 个品牌**，
被排除的同源有序对从 10462 升到 12380（总有序对 36672）。

### 第二个 fail-open 漏洞

无 assignee 记录的专利，第一版**回退到「以自身为桶」**——结果是它对全语料都显得异源。
已改为**返回未知 → 直接剔除**。

## 本次撤回的一个测量（方法学错误）

初版还算了「强制异源相对同源的 spec 距离代价」，**该数字无效、已撤回**。
`rank_seeds` 的距离是**按候选池 min-max 归一**的，两次不同池的调用结果不在同一标度上
（对照组里出现了 `-7.4` 这种量级不合理的值，与其余 0.03–0.5 的分布完全不兼容）。

**仍然有效的是 argmin**（选中哪颗 seed），但**理由不是「单调归一不改排序」**——
`rank_seeds` 对**每个维度**按该池自身 min/max 归一，换池会改变**维度之间的相对权重**，
这不是单调变换。**正确理由**：单次调用内所有候选共享同一套归一化常数，
故**该次调用内部的排序是良定义的**；跨调用标度不同，所以距离不可比。
（本行措辞于 2026-07-28 自查后更正；结论未变。）
所以本文只报计数，不报距离。

  若提升，样本量会变，须重跑。
- 「每个对照取一颗最近 seed」只是**最简配对协议**，不是已裁定的 P2 协议。
  seed 复用集中说明可能需要换协议（如每个对照取 k 颗、或按 spec 分层配额）——**未设计**。
- 品牌桶的代表字符串取自同组内字典序最小者，**只是标签**，不代表法律实体
  （例如 Sunny 组的代表可能是某个汽车光学子公司名）。分组本身与标签无关。
