# P2 对照组像质基线首测（2026-07-28）

**一句话**：底库此前**一个 MTF 数、一个畸变数都没有**——而北极星 P2 的判据正是
「候选在 **RMS spot / MTF / 畸变** 三项上不劣于对照」。本次首测拿到基线，
并抓到**第 6 个退化模式**：3/30 颗报出 **10²⁰ µm 量级**的点列径，
**通过了既有的 `>0` 自证型检查**。

## 为什么必须先做这个

`.planning/NORTH-STAR.md` §1.1 把异源打平率定义为三项比较。可追迹率普查只测了
**逐视场点列径**，**MTF 与畸变从未被测过**。没有对照侧的数，候选无从被判。

本次**只测对照侧**，**不做任何优化**：导入 → 调生产的指标函数 → 出数。

## 判准（沿用项目已付过学费的两类）

- **自证型**：RMS 点列径、RMS 波前为正定量，`<=0` 即「从未测得」；
  `@mtfmin` 起始 1 且只减，正频率下衍射把 MTF 严格压在 1 以下，故 `>=1.0` 自证
- **联合判据**：畸变与横向色差的 `0.0` 物理合法，仅当两个正定量同时塌缩时才扣留

## 结果（30 颗「严格可追迹 ∧ 保真度干净」seed，全部测得）

物理合理的 27 颗分布：

| 指标 | min | p25 | **中位** | p75 | max |
|---|---|---|---|---|---|
| RMS 点列径 | 3.97 | 7.23 | **10.4 µm** | 19.3 | 444 |
| MTF @100 lp/mm | 0.00212 | 0.0738 | **0.312** | 0.526 | 0.623 |
| 畸变 | 0.278 | 1.37 | **1.72 %** | 2.14 | 21.5 |

（MTF 频率 100 lp/mm、`nrd=32`，与生产 `_DEFAULT_TOLERANCE_MTF_FREQUENCY_LPMM`
及 `_DEFAULT_TOLERANCE_NRD` 一致。）

**这三个中位数是 P2 门槛的实测输入**——按北极星红线③，门槛数值**仍不得先验拍板**，
但现在它至少有了可复算的分布，而不是零数据。

## ⚠️ 第 6 个退化模式：荒谬的大数，方向与前五个相反

| seed | RMS 点列径 | MTF | 畸变 | 波前 |
|---|---|---|---|---|
| `US-11719917-B2-e4` | **5.578e+20 µm** | 1.451e-37 | None | None |
| `US-11719917-B2-e5` | **8.261e+20 µm** | 2.713e-37 | None | None |
| `US-11719917-B2-e6` | **7.811e+20 µm** | 5.764e-38 | None | None |

10²⁰ µm = 10¹⁴ 米，**比整个像圈大十四个数量级**，物理上不可能。

**为什么既有防线没拦住**：项目此前五个实例全是「**退化值恰好等于理想值**」
（`@rmssum` 起始 0、`@mtfmin` 起始 1.0、`SPOTDATA` 轴上 0.0 等），
于是判准写成「正定量 `<=0` 即未测得」。**这一个的退化方向是 +∞ 而不是 0**，
`>0` 检查照单全收。

**部分被拦住的地方**：联合判据确实扣留了畸变与横向色差（因为波前同时塌缩），
所以 `dist=None`。**但点列径与 MTF 被原样报出**——而这两项正是 P2 的判据。

**建议的自证型上界（不用拍任意常数）**：**点列径不得大于像圈**——
一个比整幅像还大的「点」不是像。用 seed 自身的像高作界，无需引入魔数。

## 对 P2 的直接后果

**「严格可追迹 ∧ 保真度干净」（192 颗）不足以充当对照组。** 实测质量跨度：
`3.97 µm` → `444 µm` → `10²⁰ µm`。拿 444 µm 或荒谬值当对照，候选**轻易「打平」**，
**主指标被推高**——与保真度缺陷同一个方向的偏置。

**对照组需要第三道筛**（可追迹 / 保真度 / **像质合理性**），门槛按红线③实测后再定。
