# P4 首个读数：一阶量跨引擎可复现，主指标依赖的那个量不可（2026-07-29）

> ⚠️ **Optiland 是第二个引擎，不是第三方。** 两个引擎一致 ≠ 第三方一致。
> 本页不声称 P4 已闭合，只是把它从「零数据」变成「有数据」。

**一句话**：拿 2026-07-29 那 6 条 trial 的 12 侧 ZMX，用 **Optiland**（与 CODE V 完全独立实现的
序列光线追迹）重算——**EFL 复现到 0.04%、F/# 逐位相同，而 RMS 点列径只有 CODE V 的 0.19–0.70 倍**。
北极星主指标恰恰判在**不可复现**的那一类量上。

## 方法

对每条 trial 记录里的候选与对照 ZMX：Optiland 重算 EFL / F/# / 各视场最大 RMS 点列径，
与 trial 里 CODE V 记下的数对比。视场角**取自文件自身**（`YFLN`），不取 manifest——
manifest 正是被证实带两种单位的那一列（`fov-unit-mix-2026-07-29.md`）。
每次重算独立子进程 + 超时隔离（Optiland 在本语料上有已知挂死）。

## 结果

| 量 | n | 比值中位（Optiland / CODE V） | min | max |
|---|---|---|---|---|
| EFL | 7 | **0.9997** | 0.9996 | 1.0004 |
| F/# | 7 | **1.0000** | 1.0000 | 1.0000 |
| **max RMS 点列径** | 7 | **0.4925** | **0.1906** | **0.7040** |

**Optiland 在 12 侧里有 5 侧算不出来**（`engine_failed`）——
也就是说一个拿 Optiland 复核的第三方，**42% 的读数根本拿不到**。
按项目既有认知，这不等于「镜头坏」：本语料已实测过 CODE V 追得出而 Optiland 追不出的样本。

## 这个差不是我们自己的裁剪造成的（至少不全是）

`compute_mtf` 会做一次 MAD 稳健裁剪（`_robust_clip_spot_data`），削掉渐晕伪迹光线。
关掉它重测：

| ZMX | CODE V (µm) | 裁剪后 | **不裁剪** | 裁剪/cv | **不裁剪/cv** |
|---|---|---|---|---|---|
| `US-11906710-B2-e5` | 6.995 | 1.333 | 2.742 | 0.191 | 0.392 |
| `US-12210142-B2-e1` | 4.120 | 1.211 | 1.784 | 0.294 | 0.433 |
| `US-20240201471-A1-e4` | 3.975 | 1.958 | 2.465 | 0.493 | 0.620 |
| `US-20250370227-A1-e12` | 9.201 | 6.477 | 6.477 | 0.704 | 0.704 |
| 候选 `_target005312_` | 268.970 | 135.907 | 135.907 | 0.505 | 0.505 |
| 候选 `_target008574_` | 188.885 | 130.696 | 130.696 | 0.692 | 0.692 |
| `US-20230288669-A1-e2`（超广） | 4.647 | 2.120 | **278.930** | 0.456 | **60.0** |

- 裁剪**解释了一部分**：3/7 的比值从 0.19/0.29/0.49 抬到 0.39/0.43/0.62。
- 裁剪**什么都没解释**：另外 3/7 裁剪前后逐位相同。
- **即使完全不裁剪，Optiland 仍只读到 CODE V 的 0.39–0.70 倍。** 这是真的引擎/定义差异。
- ⚠️ 那颗超广角是反例中的反例：不裁剪时读出 **278.9 µm**（60×）。
  **对这一类镜头，我们报的数严重依赖我们自己的裁剪选择。**

## 对北极星的意义

NORTH-STAR §3 的 P4 要求「第三方拿我们的 ZMX 复算出我们报告的**每个**数字」。
按本次读数：

- ✅ **EFL / F/#** ——一阶量，**从 ZMX 本身就能复现**，外人查得了。
- ❌ **RMS 点列径** ——主指标三项判据之一，**复现不了**。差 1.4–5.2 倍，
  且差多少与镜头好坏相关（对照 0.19–0.49、候选 0.51–0.69），**不是一个能在
  候选/对照比值里相消的常数**。
- ⬜ **MTF / 畸变** ——本次**没测**（Optiland 的 MTF 频率与视场集与 CODE V 侧不同口径），
  所以 P4 的覆盖是**部分的**，不得表述为"三项都验过"。

**结论**：光导出 ZMX 不足以让人复算我们的像质数——那个数还依赖视场集、光线密度、
裁剪规则这些**没写进 ZMX 的管线选择**。要么随交付物一并发布测量配方，
要么改报一个与配方无关的量。**这是 P4 现在真正的缺口，不是"还没找人来复核"。**
