# 存量路由像质与 CODE V 差到 188 倍（2026-07-30）

追 `par = 0` 的根因时（`p1-root-cause-routing-gate-2026-07-30.md`）发现路由质量闸读的是
**存量 Optiland 半径**而判决读 **CODE V 全场直径**。本页把这个分歧**在全库上量化**。

## 方法

对每个语料案例取两个读数，**都换算成直径**再比：

- **CODE V**：`trace-census-20260728/census.jsonl` 的 `rms_spot_um`
  （`@rmssum` 同源：`SPOTDATA(...) -> ^spot(1)` × 1000，是直径）
- **存量 Optiland**：`app/data/optical_cases/<case>.json` 的
  `mtf.rms_spot_radius_um_by_field` 取最大值 **× 2**（半径 → 直径）

## 结果（n = 315 同时有两侧读数的案例）

| CODE V / 存量（同为直径） | 值 |
|---|---|
| min | 0.207 |
| **中位** | **1.72** |
| **max** | **208** |

| | |
|---|---|
| 存量低估 **>2 倍** | **119/313（38.0%）** |
| 存量低估 **>5 倍** | **36/313（11.5%）** |
| 存量像质**只测到部分视场**（`mtf_max_field_frac < 1`） | **297/315（94.3%）** |

## 决定性个例

| 案例 | CODE V | 存量（直径） | 比值 | `mtf_max_field_frac` |
|---|---|---|---|---|
| **`US-12436366-B2-e10`** | **447.60 µm** | **2.38 µm** | **188.3** | 0.5 |
| `US-12044826-B2-e4`（承担 41/49 trial） | 101.27 | 51.11 | 1.98 | 0.5 |
| `US-11668898-B2-e6` | 11.80 | 2.07 | 5.71 | 0.5 |
| `US-20260063869-A1-e3` | 57.50 | 49.93 | 1.15 | 0.5 |

⇒ **一颗 CODE V 认定 447 µm 的镜头，在存量里长成 2.38 µm —— 看起来是全库最好的镜头之一。**
这就是它如何钻过 `_SEED_ROUTING_MAX_RMS_UM = 100.0` 那道闸的。

## 机制

**94% 的存量像质只测到部分视场**（绝大多数 `mtf_max_field_frac = 0.5`）。
RMS 向边缘陡增，所以半场测量**系统性低估**，且低估幅度取决于该镜头边缘有多坏 ——
**越坏的镜头被低估得越多**。这正好是最有害的方向：**闸对最该挡的样本最盲。**

## 影响面（不止 P2）

`_SEED_ROUTING_MAX_RMS_UM` 与 `_SEED_ROUTING_MIN_MTF_50` 是**产品自己的**
seed 路由闸（`app/core/case_library.py:168-169`）。
⇒ **演示现场也可能路由到一颗 CODE V 认定 447 µm 的镜头，而系统相信它是 2.38 µm。**
这是**演示可信度级**的缺陷，不只是 P2 的度量问题。

P2 侧已修：比较器的 seed 池改按**语料中位数**设闸，量取自 perfield census
（与判决同源同视场同单位），实测**零 trial 代价**、seed RMS 中位 101.27 → 8.75 µm。
**产品侧路由未动** —— 它在无 runtime census 的环境也必须能跑。

## 出路（未实施）

1. **把 CODE V 的全场读数固化进语料索引**（`index.json` 加一个字段 + provenance），
   让产品侧路由能在无 census 环境用同一把尺子。
2. 或**把存量像质重算到全视场**（`mtf_max_field_frac = 1.0`），消掉半场低估。
   代价：Optiland 在部分语料上追不出来（本条那颗 seed 我实测 native 与 rebuilt 都 FAILED），
   所以会出现「重算不出来」的空洞，必须 fail-closed 而不是留旧值。
3. 无论走哪条，**闸的阈值都要按对照分布标定**，不能沿用「挡掉坏 ingest 件」的量级。

## 诚实边界

- n = 315，不是 442：其余案例缺一侧读数（CODE V 不可追迹或存量无 MTF）。
- 比值 min 0.207 说明也有反方向的（存量**高估**），所以这不是单调偏置，
  但**分布明显偏向低估**（中位 1.72）。
