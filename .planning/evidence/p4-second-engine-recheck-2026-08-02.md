# P4 第一次有分布：`engine_failed` 22→0，三项判据的 n 从 2 抬到 18–30（2026-08-02）

`.planning/NORTH-STAR.md` §3 记 P4「一阶量可复现；**RMS/MTF 全视场 n=2**，逐颗不可复现」，
绑定约束写的是「**第二个引擎整侧测不出来**」——曾 22 次重算 18 次 `engine_failed`。

那个数字来自一次 **6 条 trial** 的跑批（`p2-gated-20260729`）。
`scripts/p4_independent_recheck.py` 已在 main 上、**只用 Optiland、不碰 CODE V**，
而**从没有人把它指向 2026-08-02 那一轮 49 条 trial**。本页就是那次重算。

```bash
uv run python scripts/p4_independent_recheck.py \
  --run D:/atelier-p1-runs/p1-selectpref-ab-20260802 \
  --out .planning/evidence/p4-second-engine-recheck-2026-08-02.json --timeout 180
```

## 一、绑定约束没了

| | 旧（6 条 trial） | **本次（49 条 trial）** |
|---|---|---|
| 重算次数 | 22 | **188**（94 侧 × 2 arm） |
| 不同 ZMX 文件 | — | **72**（27 个对照设计 + 45 个候选） |
| **`engine_failed`** | **18 / 22** | **0 / 188** |
| truncated（抢救回来的） | — | 2 |

PR #163 的**逐视场降级**把整侧失败清零了。这不是「重跑一次运气好」——
188 次里一次都没有。⇒ **P4 的绑定约束从「第二个引擎测不出来」变成了「两个引擎读数差多少」**，
后者是可以看分布的。

## 二、一阶量：EFL 是真复现，**F/# 是退化值——不要引用它**

| 量 | n | 中位 | 区间 | 是不是真的复现 |
|---|---|---|---|---|
| EFL | 94 | **0.9997** | 0.659 – 1.0008 | ✅ 是 |
| F/# | 94 | 1.0000 | min = max = 1.0 | ❌ **不是** |

### ⚠️ F/# 的 100% 一致是同义反复，本页把它撤下

初稿把「94 个侧的 F/# 全部逐位一致」当成最强的一致性证据。**它不是证据。**
实测（逐行比对 ZMX 原文与两侧读数，94/94）：

```
US-11906710-B2-e1.zmx   ZMX_FNUM=2.2   ENPD=-   codev=2.2   optiland=2.2
US-11668898-B2-e6.zmx   ZMX_FNUM=2.05  ENPD=-   codev=2.05  optiland=2.05
...
checked 94 rows: both engines exactly equal the ZMX declared FNUM in 94 of them
```

这批 ZMX 的孔径是用 **`FNUM`（像方 F/#）**声明的、**没有 `ENPD`**，
所以两个引擎都是把**声明值读回来**，谁都没有算它
（Optiland 侧 `optic.paraxial.FNO()`，见 `scripts/p4_independent_recheck.py:141`）。
`min = max = 1.0` 是**按构造必然**的，不是两个引擎独立得到了同一个数。

**这是本项目「退化值恰好等于理想读数」的第 12 例，而且是我自己写进证据页的。**
判别方法就摆在同一张表里：**EFL 有散布（0.659–1.0008）⇒ 它被算了；
F/# 一位不差 ⇒ 它被抄了。** 完美读数应当先被怀疑，不是先被引用。

⇒ **P4 的一阶量证据只有 EFL 一项**，n=94、中位 0.9997。
EFL 只有 **4 行（= 2 个设计）**偏离 >2%，且两者比值**都恰好是 0.6590**：

> **1 / 0.6590 = 1.5175 = 盖板玻璃折射率。**

这正是 memory 里记着的那条已知伪影（41/440 差 1.5177 倍），
且这两颗（`US-20220011544-A1-e2/e5`）在 trial 里**已经被 `control_engine_disagreement` 挡掉、
没有参与判决** —— 与 `summary.json` 的 `control_engine_disagreement: 2` 对上。

## 三、三项判据：第一次有分布（**只取全视场**，逐侧分开）

⚠️ **部分视场读数一律单列，绝不与全视场合池** —— 合池会把 MTF 中位从 0.68 抬到 1.00
（本页初稿我自己就先算错过一次，见第五节）。

| 判据 | arm | 候选侧 | 对照侧 |
|---|---|---|---|
| RMS spot | `reported` | n=18 中位 **1.0439** | n=23 中位 **0.7569** |
| RMS spot | `recipe` | n=18 中位 1.6221 | n=23 中位 1.1236 |
| MTF min | `reported` | n=18 中位 **0.6836** | n=23 中位 **0.7999** |
| MTF min | `recipe` | n=18 中位 0.8117 | n=23 中位 0.7464 |
| 畸变 | 两 arm 同 | n=23 中位 **0.8696** | n=30 中位 **1.0297** |

（比值 = Optiland / CODE V。1.0 = 两引擎读出同一个数。）

**读法**：

- **畸变对照侧最接近**（1.0297）——它是几何量，最少依赖采样约定。
- **MTF 两侧都偏低约 20–32%**，不是只有候选侧。这是**系统性偏置不是散点**，
  方向一致，说明两个引擎的 MTF 采样/瞳孔约定不同，而不是某一侧的数据坏。
- **RMS 的候选侧（1.04）比对照侧（0.76）更接近 1**。这个方向出乎意料，
  本页不解释它，只记录。

## 四、发布配方买到了什么——第一次量化

`reported` 与 `recipe` 两个 arm 的差别就是**我们报数时的 MAD 离群剔除开不开**。

| | 候选 | 对照 |
|---|---|---|
| RMS `reported` → `recipe` | 1.0439 → **1.6221**（+55%） | 0.7569 → **1.1236**（+48%） |
| MTF `reported` → `recipe` | 0.6836 → 0.8117 | 0.7999 → 0.7464 |
| 畸变 | 不变 | 不变 |

⇒ **一个第三方照我们发布的配方复算 RMS，会比照我们实际报数的口径复算高出约一半。**
这不是「配方错了」，是「我们报的数经过了一道配方没写的处理」。
**P4 要闭合，这一道必须要么写进配方、要么从报数里去掉——两者选一，不能两头都不说。**

## 五、⚠️ 我在本页初稿里犯过的两个错（都保留下来）

**其一 · 合池**：第一次分层时我把 MTF 按 `side` 聚合却**没有按 coverage 过滤**，得到
「对照侧 1.0017 / 候选侧 0.6836」，据此写下「系统性偏置只在候选侧」。
按全视场重算后是 **0.7999 / 0.6836** —— **两侧都偏低，那条结论是错的**。
错因正是这个项目已经记过的那一条：**部分视场读数与全视场合池会把数推好看**。

**其二 · 把退化值当证据**：初稿把 `F/# n=94 min=max=1.0` 写成最强的一致性证据，
实际上两个引擎都只是把 ZMX 声明的 `FNUM` 读回来（见第二节）。**完美读数应当先被怀疑。**
这一条是我在**给对抗审查者列风险清单时点名的那一条**，然后自己动手验掉的——
说明「怀疑完美读数」这条纪律有效，但它必须在**写进证据页之前**执行，不是之后。

## 六、诚实边界

- **Optiland 是第二个引擎，不是第三方**（产物 `caveat` 字段原话）。
  两个引擎一致，只说明这个数**能从导出的 ZMX 单独重算出来**，不等于 P4 闭合。
- **对照侧的 n 被重复放大**：49 行对照只来自 **27 个不同对照设计**。
  候选侧 45 行是 45 个不同文件。**报比率时对照侧的独立样本是 27 不是 49。**
- **全视场子集不到一半**：RMS/MTF 的 coverage census 是
  `complete 41 / partial 47 / none 6`。本页只用 complete 那 41。
- **门槛仍未定**。NORTH-STAR §3 说 P4 是「复算出我们报的**每个**数字」，
  **无容差 ⇒ 按字面口径永远可判失败**。本页给的是**分布**，
  按红线③这正是定门槛前必须先有的东西；**门槛本身待主公见分布后裁定，本页不拍。**
- 未跑 CODE V：所有 CODE V 侧的数字都是 2026-08-02 那轮跑批**当时记录**的，不是重跑的。
