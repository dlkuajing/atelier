# 固定畸变硬约束的剂量-反应：约束形式也买不到畸变（2026-08-04）

**一句话**：约束**被严格执行**（候选畸变精确落在 bound 上），但代价是
**RMS 中位放大 56–71 倍、MTF 中位掉到 2–3%**——**与加权形式同样的塌陷**。
两种机制各有一条剂量-反应曲线，**结论一致：对这批 seed，畸变买不回来。**
⇒ P2 的卡点**不在优化器**，在 **seed 供给与异源规则**，而那是主公口径决策。

**run 目录**：`D:/atelier-p1-runs/p2-distfixed{3.0,1.5,1.0}-20260804`
**对照臂**：`p3-fourpiece-20260804`（bound = none，同一代码）
**成本**：三臂 × 12 条 ≈ 15 分钟真机。红线① pre/post 均 0，全程监控无 ALERT。

## 为什么要做这个实验

上一版结论写的是「重新加权 = Pareto 前沿，畸变买不回来」。复算后发现
**那只证伪了加权形式**：加权 arm 在最小档 w=0.01 就把候选 RMS 从 1.84 µm 打到 456 µm
（×44.5）——**那不是交换，是优化器崩了**。

而唯一测过的**约束** arm（`--distortion-bound -1`）发进 `.seq` 的是
`@atelier_distortion < ^seed_baseline_max_distortion_pct`，即**「待在你自己的 15.8%」**，
**根本没要求把畸变压下去**，所以它 RMS 比 1.0000「几乎免费」不能外推。

**固定低 bound 从未测过。** 本实验补上。

中位精确贴着 bound ⇒ 复现了仓库自己记的「优化器把配额花光」
（`codev_optimize.py:659-664`）。**约束不是装饰，引擎真的在守它。**

## 代价：和加权形式一样的塌陷

配对同一条对照，相对 bound=none 臂：

| arm | 畸变 | **RMS** | **MTF** | aut 未收敛 |
|---|---|---|---|---|
| bound 3.0 | ×0.184（−13.28 pp） | **×71.34**（max 803.7） | **×0.0317**（min 0.0002） | 1 |
| bound 1.5 | ×0.096（−14.13 pp） | **×61.30**（max 481.8） | **×0.0226** | 1 |
| bound 1.0 | ×0.059（−15.08 pp） | **×56.18**（max 259.3） | **×0.0304** | 1 |

逐条（bound 1.5）：

```
control                base d%  ->  1.5    | base rms -> 1.5 rms   1.5 mtf
US-11933948-B2-e11      19.981 -> 1.501    |    1.577 -> 759.731   0.0021
US20170045714A1         15.632 -> 1.500    |    2.560 -> 321.782   0.0018
US9239447B1             27.427 -> 1.486    |    2.834 -> 336.983   0.0170
US-20240201471-A1-e1    15.041 -> 1.500    |    1.695 -> 235.956   0.0239
US-12436366-B2-e11       0.804 -> 0.804    |    1.644 ->   1.644   0.7306   <- 唯一没被动的
```

**1.58 µm → 760 µm 换 20% → 1.5% 的畸变，这不是设计，是废品。**

## 反例恰好证明了机制

`US-12436366-B2-e11` 的 seed 基线畸变**本来就是 0.804%**，于是三档 bound
（3.0 / 1.5）**一点代价都没有**——RMS 1.644 不动、MTF 0.7306 不动。
到 bound=1.0 才开始动（0.804 → 1.000，因为约束是 `<` 不是 `≤` 目标，
优化器把配额花到 1.000）。

⇒ **seed 的畸变已经够好时，约束免费；seed 是 17% 时，约束要拿两个数量级的像质去换。**
**这不是优化器强弱问题，是设计形式没有那个自由度**——
承担 43/49 的那颗 seed 是一颗**被设计成桶形、靠软件后校正的超广角**
（专利自身 f / ImgH / DFOV 蕴含 f·tanθ 畸变 −32.9%）。

## 结论：优化器这条路已封闭，两条机制各有曲线为证

| 机制 | 最小档代价 | 曲线 |
|---|---|---|
| 加权 WTC | w=0.01 → RMS **×44.5** | 0.01 / 0.1 / 1.0 三档单调 |
| **固定硬约束** | B=3.0 → RMS **×71.3** | 3.0 / 1.5 / 1.0 三档单调 |

**下一铲不在 `scripts/` 里。** 能改变 P2 的是这四件，**全部是主公口径决策**：

1. **异源定义：受让人 → 专利族。** 存在性证明已在库里——`US-12044826-B2-e4`
   用 seed `US-12282142-B2-e7`（基线畸变 **2.025%**）产出候选 **0.2357%**，
   RMS 10.6 µm。只用过一次，因为它受让人是 LARGAN，而 **48/49 条对照是 LARGAN**。
   它 EFL 可达 45/49、|Δfov|≤15° 也 45/49。**能力在，规则不让用。**
2. **限制单一受让人在对照集里的占比**（今天 48/49 = 98%）。
3. **采购非 LARGAN 的广角 rectilinear 处方**（数据采集任务，非测量任务）。
4. **接受主指标在当前语料上由一件专利决定**，并如实这样报。

⚠️ **做 seed 畸变普查不是下一铲**：43 条决定性 trial 的异源合格域被
brand × EFL±25% × |Δfov| × rms≤10.2312 四条钉死在 **SAMSUNG 一族 9 个设计**，
**普查加不进一个条目**。
