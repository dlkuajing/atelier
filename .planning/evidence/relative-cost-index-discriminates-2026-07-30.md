# 相对成本指数是有分辨力的（2026-07-30）

## 为什么要查这个

四件套第四件是「相对成本指数」。它有一个明显的退化失败模式：**如果模型被某个
不区分设计的量主导，它会对任何一对镜头都返回 ≈1.0**，看起来像在工作、实际上什么都没测。
本项目已经中过 11 次「退化值等于理想读数」，所以这一件在被当作交付物之前必须先自查。

触发这次检查的是一条可疑读数：`US-11906710-B2-e2` 报 ratio **0.9914**，
而候选的**元件数与非球面数都更少**（6/10 vs 对照 7/12）。更简单却几乎同价，看起来不对。

## 实测（全部已完成 trial）

n = **24** 条带成本比值的 trial：

| | |
|---|---|
| min | **0.4884** |
| p25 | 0.8330 |
| median | 0.9913 |
| p75 | 1.1462 |
| max | **1.4463** |
| 落在 1.0 ±5% | **4/24** |
| 落在 1.0 ±2% | **2/24** |

⇒ **不退化。** 跨度接近 3 倍，只有 1/6 的样本贴在 1.0 附近。
那条 0.9914 是巧合，不是模型的性格 —— **我的怀疑是错的，这里记下来。**

## 逐条抽样

| trial | ratio | units 候选/对照 | 元件 | 非球面 |
|---|---|---|---|---|
| US-20250370227-A1-e12 | **0.4884** | 32.50 / 66.53 | 5/9 | 8/16 |
| US-12210142-B2-e1 | 0.6964 | 26.98 / 38.74 | 5/8 | 8/14 |
| US-20230288669-A1-e2 | 0.7135 | 29.08 / 40.76 | 6/8 | 10/8 |
| US-12436366-B2-e11 | 1.0460 | 35.18 / 33.63 | 5/6 | 8/10 |
| US-20240201471-A1-e4 | 1.1904 | 28.53 / 23.96 | 6/7 | 10/12 |
| **US-11668898-B2-e6** | **1.4463** | 29.55 / 20.43 | **6/6** | **10/10** |

最后一行值得留意：**元件数与非球面数完全相同，成本仍差 45%** ⇒ 差异来自材料与口径/厚度，
不是来自计数。这正是成本模型应该有的行为（同样的片数、不同的玻璃和尺寸不该同价），
但它也意味着**这一件的读数强依赖材料解析**，而 425/442 颗语料案例的
`metadata.materials` 是空的 —— 成本模型走的是 ZMX 的 `GLAS` 行 + nd 回退，
**不是** `metadata.materials`（已核对：`app/core/cost_index.py` 只读 ZMX）。
两者不要混起来。

## 顺带确认的口径

`cost_index` 把**红外截止 / 保护玻璃平板也计为一个元件**（它有真实 `GLAS` 行）。
对「成本」而言这是对的 —— 那是一个要采购的零件。且两侧走同一个解析器，**对称**，
所以不会造成候选/对照之间的口径不一致。
（与 `generate_cases.py` 的 `n_pieces` 把平板算成镜片是**不同的问题**：那个数是光学片数语义、
会成为候选的片数目标；成本这里不消费它。）

## 诚实边界

24 条 trial 全部来自 5 颗 seed 设计中的少数几颗（见
`.planning/evidence/seed-field-headroom-2026-07-30.md`：一颗 seed 承担 41/49）。
「不退化」这个结论对**模型**成立；跨设计的分布还没有独立样本支撑。
